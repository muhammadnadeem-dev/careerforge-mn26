# CareerForge

**Your career, built with confidence.**

CareerForge is an AI-powered career preparation platform designed to help students and job seekers prepare for their next opportunity.

## Features

- **AI Career Assistant:** Ask career-related questions and receive guidance.
- **Résumé Analyzer:** Upload a PDF résumé and receive AI-powered feedback.
- **Job Matcher:** Compare your résumé with a job description and identify areas of alignment.
- **Interview Coach:** Practice interview questions and improve your answers.
- **Chat History:** Create, revisit, rename, and delete conversations.

## Technology

- React
- TypeScript
- Vite
- DeepSpace SDK
- Tailwind CSS

## Local Development

Install dependencies:

```bash
npm install
```

Start the development environment:

```bash
npx deepspace dev start
```

Open `http://localhost:5173` in your browser.
